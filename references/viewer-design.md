# 离线导读界面的维护依据

维护 [固定模板](../assets/study-viewer.html) 的 UI 时读本分册。保留“关系地图 / 路线导学 / 源码精读”三种视图与单文件离线运行；项目事实依照 [数据合同](project-data.md) 注入，界面不能改变来源、证据等级或用户学习状态。

## 设计方向与参考

这是用于学习的开发者工作台。地图和源码导航服务操作，课程主体服务理解；白灰或深色中性背景、青绿色选中状态、细分隔线和少量圆角保持一致。使用系统中文正文字体与代码等宽字体，避免为页面新增字体下载或运行依赖。

| 参考 | 借鉴的交互或结构 |
|---|---|
| [Sourcetrail 的界面说明](https://github.com/CoatiSoftware/Sourcetrail/blob/master/DOCUMENTATION.md) | 当前符号、关系与源码联动，关系有可定位的源码出处 |
| [Starlight](https://starlight.astro.build/) | 章节导航、清晰阅读层次、正文行距、代码与讲解的分工 |
| [VS Code 的界面说明](https://code.visualstudio.com/docs/getstarted/userinterface) | 文件与符号导航、面包屑、辅助面板、返回前一阅读位置 |

这些是设计参考；模板的实现独立维护，不将参考项目作为运行依赖。

## 交互约束

- 节点显示真实类型，符号导航显示所属类或外层函数。文件夹只表示源码分布，不能推断逻辑架构。
- 文件视图按同方向起点、终点聚合关系，摘要包含全部筛选内原始边 ID，点击后逐条列明类型、状态及出处。不同证据状态混合时明确标为混合依据，不能用单一“源码确认”代替。符号视图保持具体关系身份。
- 默认主干总览展示调用、事件、配置等连接；纯辅助导入、明确初始化及反向数据关系可折叠，显示准确折叠数并保留完整关系入口。主干连接中包含的辅助原边仍可查看。主干模式在当前筛选集合上生效，无主干的项目回退全量；完整模式和文件邻域展示对应范围的全部连接。模式切换保留筛选，明确清除才重置。展示顺序不表示运行时序。
- 相邻层的连接使用曲线，每个节点按全部入/出连接统一分配端口，双向关系文字分开。跨层、同层和回返连接放在具名列表中，端点有计数提示及列表快捷入口，避免边缘长线或节点遮挡。完整文件关系必须能从图或具名入口逐组访问；文件内及外部/未知目标由当前符号和源码明细查看。
- 点图中节点进入文件邻域，有返回总览入口；小屏使用按节点组织的关系列表，点模块后定位源码详情。地图中的当前节点原始关系可展开，避免把小屏源码推到长明细后。其他已收录文件可展开，未在图中出现不等于死代码。
- 连线支持指针及 Enter / Space 选择，关系列表提供等效按钮。实线、虚线、点线与文字共同表达证据状态；不只依赖颜色。
- 选边后显示真实连接依据；优先定位起点所在文件的出处，其他出处可逐一打开。未知或外部节点不借用调用者源码充当定义。
- 面包屑指向真实文件或父符号。导航历史保存本页的视图、节点、焦点行、选边和路线位置；它是访问记录，不是掌握程度。按来源哈希复用保存位置，源码变化时不得恢复错位的旧证据选择。
- 课程步骤可直接跳转，并可在地图定位当前站点。多路线在主内容区提供切换，保存作答/笔记有就地反馈。序号表示阅读位置，不能据此新建调用关系或记为已理解。草稿在本页重绘时保留，明确保存才进入持久记录。
- 小屏默认折叠路线目录与文件索引，保留紧凑入口；切换阅读位置后定位正文。源码版本与项目根放在可展开的来源信息中，避免长路径挤占学习区域。

## 源码显示与文字层次

基础着色只识别关键词、字符串、注释、数值和部分函数名称，用于阅读。它不负责语义索引或确定调用目标；非自动分析语言仍需有依据的符号与关系注解。

源码逐行保留字符，以 DOM `textContent` 显示；着色不得改写字符、用 HTML 执行源码、截断完整文件或重新编号片段。完整源码和复制内容来自同一份原文。未覆盖语言保留普通文字显示。

课程标题、解释、理解题与辅助标签有明确大小和间距差异，长正文采用适宜行长。代码可在自身容器中横向滚动，不能造成整页横向溢出；深色主题、选中行和焦点状态均保持文字可读。

## 核对与刷新

模板修改后按 [project-view.md](project-view.md) 重新生成实际示例，直接通过本地文件打开核对。按改动补查选边、全部出处、符号身份、面包屑、返回、课程草稿和原文保持。桌面、小屏与深色页面统一检查，发现实际缺陷后集中修复，避免重复截图与零碎调整。

复用未修改生成器和相同源码状态的验证。结构检查、自动交互测试和读图各说明范围；它们都不能代替真实学习者的理解证据。
